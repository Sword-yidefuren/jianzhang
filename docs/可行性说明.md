# 简账 · 可行性说明

结论先说：**“实时自动读取微信/支付宝每一笔收支”做不到；但“官方账单导出 → 本地导入 + 自动分类去重”和“一句话记账”都可行，而且可以完全离线。**

## 1. 三条路线，分别能不能做

| 路线 | 结论 | 原因 |
| --- | --- | --- |
| 实时同步微信/支付宝账单 | **不可行** | 个人账户没有公开的交易读取 API。微信支付、支付宝开放平台只面向商户/服务商，权限与账单主体都不是个人。客户端数据在各自沙箱里，第三方 App 无法稳定读取。 |
| 安卓通知监听（实验性） | **部分可行，但不作为主路径** | 开启通知使用权后可捕获部分“微信支付/支付宝”收款通知，但只有金额和商户片段，漏通知、重复通知、营销通知都会造成错账；iOS 完全不可用；上架审核也有风险。 |
| 官方账单 CSV 导入 | **可行，推荐** | 微信、支付宝都提供官方账单导出（邮件/下载），解压后得到 CSV。导入后本地解析、分类、按交易单号去重。缺点是必须手动导出，且有延迟。 |
| 一句话记账 | **可行，推荐** | 中文记账句规律强，金额、收支方向、日期、账户、分类都能用本地规则解析；不联网、不调用大模型，输入即出结果。 |

## 2. 为什么不碰“无障碍自动操作”

用无障碍服务模拟点击微信/支付宝，技术上能抓到界面文字，但：

- 违反两家平台的使用协议，账号有被风控的风险；
- 界面一改就失效，维护成本极高；
- 需要常驻无障碍权限，隐私暴露面比“导入 CSV”大得多；
- 无法保证不漏单，账本最怕“看起来自动、实际错了”。

所以这个项目**不做**无障碍自动记账。后续如果要提升自动化，优先做安卓通知监听的可选实验功能，并明确标注“可能漏单，需人工核对”。

## 3. 官方账单怎么拿

### 微信支付

1. 微信 → 我 → 服务 → 钱包 → 账单；
2. 右上角 → 常见问题 → 下载账单；
3. 选择“用于个人对账”，选时间范围，填邮箱；
4. 微信支付公众号会发解压码，邮件里下载加密 ZIP；
5. 用解压码解压，得到 CSV，再在 App 里导入。

微信账单 CSV 的关键列：`交易时间`、`交易类型`、`交易对方`、`商品`、`收/支`、`金额(元)`、`支付方式`、`当前状态`、`交易单号`、`商户单号`、`备注`。

### 支付宝

- 手机端：我的 → 账单 → 右上角更多 → 开具交易流水证明（按提示申请，邮件收取）；
- 电脑端：登录支付宝 → 账户余额 → 查看 → 选时间范围 → 下载查询结果（可编辑的收支明细）。

支付宝 CSV 的关键列：`交易号`、`交易创建时间`、`交易对方`、`商品名称`、`金额（元）`、`收/支`、`交易状态`、`备注`。

> App 只接收**解压后的 CSV**。加密 ZIP 的解压放在系统里完成，App 不保存邮箱、解压码或账单压缩包。

## 4. 导入的实现边界

- 编码：同时兼容 UTF-8（含 BOM）和 GBK；支付宝旧账单常见 GBK。
- 表头：账单前面有说明行，导入器会定位真正的表头，而不是假设第一行就是列名。
- 去重：以“来源 + 交易单号”为唯一键，重复导入不会产生重复账目。
- 跳过：`收/支` 为 `/`、`不计收支`、金额为 0、缺少交易时间的行会被跳过并计数。
- 退款：先按原方向入账，备注保留原始状态；后续可加“退款冲销”功能。
- 不处理：加密 ZIP、银行账单、京东/美团等第三方账单。后续可按同样方式扩展。

## 5. 一句话记账的边界

支持的说法示例：

- `午饭 25`
- `打车 18.5 支付宝`
- `昨天 超市 128 微信`
- `工资 12000`
- `收到退款 99`
- `11月3日 房租 2800`
- `+200 红包`
- `请客 300 现金`

解析内容：金额、收入/支出、日期（今天/昨天/前天/N月N日）、账户（微信/支付宝/现金/银行卡）、分类、备注。

明确不做：一句话记多笔、借贷/转账双向分录、外币、发票 OCR。识别不准时，落库前可以点“详细记一笔”改。

## 6. 本地与隐私

- 数据库是本地 SQLite，默认位置在系统应用数据目录；
- 无账号、无云同步、无埋点；
- 导入的文件只在内存中解析，解析完不保留原文件；
- 导出的 CSV 由用户自己选择保存位置；
- 安卓 release 包不声明网络权限。

## 7. 版本路线

- **1.0（本版）**：一句话记账、手动记账、微信/支付宝 CSV 导入、分类统计、明细编辑、CSV 导出、Windows/Android。
- **1.1**：分类规则可编辑、预算、退款冲销、月度对比。
- **实验**：安卓通知监听（默认关闭）、本地小模型增强模糊语句解析。
