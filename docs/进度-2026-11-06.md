# 进度（2026-11-06）：支持 Excel 账单导入

## 问题

用户反馈微信等平台导出的账单主要是 `.xlsx`，App 无法导入。

实际有两个卡点：

1. 文件选择器只允许 `csv` / `txt`，`.xlsx` 直接选不到。
2. 导入器把所有 ZIP 开头的内容都当成“压缩包”拒绝；而 `.xlsx` 本质就是 ZIP，即使选了也会被挡下。

## 实现

- 新增 `lib/domain/xlsx_sheet.dart`，用 `archive` + `xml` 读取 `.xlsx`，不引入 Office/云端依赖。
- 支持：
  - 共享字符串（`sharedStrings.xml`）和内联字符串（`inlineStr`）
  - 工作簿关系，定位第一个工作表
  - 表头前的说明行
  - Excel 日期序列值（如 `46296.5`）
  - 金额为数值单元格
- `BillImporter` 统一接收 CSV / XLSX，再走原有表头识别、分类、交易单号去重。
- 文件选择器增加 `xlsx`；界面文案从“CSV”改为“CSV / Excel”。
- 旧版二进制 `.xls` 仍不支持，界面和 README 提示另存为 `.xlsx` 或 CSV。
- 加密 ZIP / 无效 Excel 会给出明确错误，不再笼统报“压缩包”。

## 测试

- 新增 3 个测试：
  - 微信 XLSX：共享字符串、说明行、Excel 日期序列
  - 支付宝 XLSX：无标题行、内联字符串
  - openpyxl 生成的真实工作簿：样式、日期格式、共享字符串
- 测试文件：`test/fixtures/wechat_sample.xlsx`
- `flutter test`：33 项全部通过
- `dart analyze --fatal-infos`：无问题

## 限制

- 只读取**第一个工作表**；如果导出文件把账单放在第二个 sheet，需要调整。
- 不支持旧版 `.xls`、加密 Excel、宏文件。
- 还没有用微信/支付宝**实际导出**的 xlsx 跑过；目前用的是与官方表头一致的真实 Excel 工作簿。
- Android 端的 xlsx 文件选择器尚未单独做设备冒烟，解析层已有真实文件测试。
