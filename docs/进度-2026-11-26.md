# 进度（2026-11-26）：首页合并、中间加号与年度统计

## 1. 首页和明细合并

- 删除独立「明细」Tab。
- 首页现在是：概览 → 存钱进度 → 月份/搜索/收支筛选 → 按日分组的账目列表。
- 删除「花在哪里」和「最近账目」，分类明细留在统计页。
- 导入按钮放在标题右侧。
- 旧账目、筛选和编辑逻辑不变。

## 2. 中间加号

- 手机底部：`记账 | 统计 | ＋ | 存钱 | 设置`。
- 加号打开底部面板，面板内直接显示一句话输入和实时预览，底部仍有「详细记一笔」。
- 桌面侧栏保留「记一笔」按钮，打开同一个面板。

## 3. 语音

- 使用 `speech_to_text`，先尝试 `onDevice: true`；失败时提示「用系统识别（会联网）」。
- 长按麦克风开始、松开结束；识别结果填入输入框，可修改后保存。
- 没有中文离线语音包、权限被拒或平台不支持时，提示继续打字。
- Android 增加 `RECORD_AUDIO`、`INTERNET` 权限和语音服务查询；只有语音可能联网。

## 4. 统计按年

- 增加「月 / 年」切换。
- 年视图显示自然年 1–12 月趋势、年度收支、分类占比、日均、记账天数、最大单笔。
- 点年度柱子可跳回对应月份。
- 新增 `LedgerStore.entriesForYear`、`categoryTotalsForYear`、`monthlyTotalsForYear`。

## 5. 存钱颜色

- 已存 > 0：墨绿色，不再因为未达目标而变红。
- 已存 < 0：赤陶色。
- 已存 = 0：灰色。
- 目标差额用次要文字色，超过目标时变绿。

## 6. 设置减法

- 删除数据库完整路径和 `SQLite` 技术说明。
- 本地存储只保留「N 笔，只在这台设备」。
- 关于只保留版本和一句「本地优先，不上传、不联网」。
- 同步说明缩短为两句话。

## 7. 黑白主题与 AI 分类

- 整体换成暖黑白：墨黑 `#1B1B19`、暖白 `#F6F4EF`、卡白 `#FFFDF9`。
- 分类图标和图表改用灰阶；收入/支出靠 `+/-`、字重和标签区分。
- 新增支出分类「AI使用」，关键词覆盖 ChatGPT / GPT / Claude / DeepSeek / Gemini / Copilot / Midjourney / Sora / 大模型 / API 充值等。

- 首页列表一次性构建当前月账目，数据量特别大时再改懒加载。
- 尚未在真机上验证语音；当前只完成编译和 UI 测试。
