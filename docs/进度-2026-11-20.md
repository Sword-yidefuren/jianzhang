# 进度（2026-11-20）：存钱页与固定月收入

## 新增

- 底部导航和桌面侧栏新增「存钱」页，位置在统计和设置之间。
- 存钱页显示：
  - 本月已存 = 本月收入 - 本月支出，即首页的「结余」
  - 今年已存 = 今年累计收入 - 支出
  - 本月目标、全年目标，以及完成进度和差额
- 颜色：
  - 负数或没达到目标：赤陶色，提醒还差多少
  - 达到或超过目标：墨绿色
- 首页「最大头是 xx」下面增加一行存钱进度，例如「本月已存 ¥500，离目标还差 ¥100」；没设目标时提示去存钱页设置。
- 存钱页顶部增加可选口号，例如「存够钱买手机」；留空时显示提示文案。
- 设置页新增「固定月收入」：
  - 开启后每月 1 号自动生成一笔「工资」收入，账户为银行卡
  - 关闭后不再新增，已生成的收入保留
  - 关闭即手动记收入
  - 同一个月不会重复生成；跨月打开会补上缺失月份

## 数据

- SQLite 增加 `settings` 表（`user_version = 2`），只新增表，不改旧账目表。
- 存钱目标和固定收入配置都存在本地，不联网。
- 自动收入来源标记为 `auto_salary`，交易单号为 `auto-salary:YYYY-MM`，可被导入去重逻辑识别。

## 测试

- 固定收入自动生成、重复开启不重复、跨月补记
- 存钱目标保存与重新打开恢复
- 桌面/手机五个页面切换无溢出
- 首页目标差额文案与存钱页渲染

`flutter test`：37 项通过；`dart analyze --fatal-infos` 无问题。

## 版本

1.2.0，重新构建 Android APK 与 Windows 包。

## 限制

- 固定收入固定按每月 1 号 09:00 入账，暂不支持自定义发薪日。
- 存钱目标按自然月和自然年统计，不做跨年结转。
- 本年已存是累计净结余，不包含未入账的预期收入。
