# 进度与下一步（2026-11-05）

## 今天修的三个实际问题

1. **首页金额不刷新**  
   桌面和手机都复现：记完一笔，撤销条出现了，但「本月支出」还是 ¥0。  
   原因：`AppShell` 在 `initState` 缓存了页面 widget 列表，`AnimatedBuilder` 重建时传入的是同一批 widget 实例，Flutter 直接跳过子树更新。  
   修法：每次 build 重新生成页面列表，Element 仍按类型复用，滚动位置不丢。

2. **撤销条永远不消失**  
   Flutter 3.47 起，带 action 的 SnackBar 默认 `persist = true`。  
   修法：一句话记账的 SnackBar 明确 `persist: false`，4 秒后消失。

3. **手机记账面板底部留白翻倍**  
   外层已经按键盘高度抬升，底部按钮又加了一次 `viewInsets.bottom`。  
   修法：按钮区固定 16px 底部内边距，只由外层负责键盘避让。
