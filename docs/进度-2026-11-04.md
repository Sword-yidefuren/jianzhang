## 本地环境的关键坑

1. **Flutter Windows 不能直接在中文路径构建**  
   报错 `Unable to read file ... 锟斤拷...app.dill`。  
   解决：把项目复制到 ASCII 路径（如 `C:\Users\Sword\Desktop\qianduan\jianzhang-build4`）再构建。

2. **`package:sqlite3` 默认从 GitHub 下载预编译库，当前网络失败**  
   已把 SQLite 3.54.1 amalgamation 放进 `third_party/sqlite3/`，并在 `pubspec.yaml` 配置：
   ```yaml
   hooks:
     user_defines:
       sqlite3:
         source: source
         path: third_party/sqlite3/sqlite3.c
   ```
   不要删掉这个配置，否则 Windows/Android 构建会重新尝试下载。

3. **Windows 窗口标题中的中文导致 MSVC 代码页错误**  
   `main.cpp` 已改用 Unicode 转义 `L"\u7B80\u8D26"`，不要再写回中文字面量。

4. **截图/OCR 工具要 DPI 感知**  
   `tools/capture_window.ps1`、`tools/click_window.ps1` 已调用 `SetProcessDpiAwarenessContext`。  
   高 DPI 下 Windows 逻辑尺寸 1280x820 实际是 1920x1230，不感知会截成左上角一块。

5. **调试用数据库覆盖与示例数据**  
   构建时可用：
   ```
   --dart-define=JIANZHANG_DB_PATH=<绝对路径>
   --dart-define=JIANZHANG_SEED_DEMO=true
   ```
   只用于预览，正式包不要带这两个 define。
