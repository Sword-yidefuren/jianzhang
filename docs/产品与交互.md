# 简账 · 产品与交互

## 1. 定位

一个**本地优先、打开就能记**的中文记账本。界面不堆功能，默认路径只有两条：

1. 在首页输入一句话，回车，记完；
2. 从微信/支付宝导入官方账单 CSV / Excel（.xlsx），自动分类、去重。

## 2. 信息架构

底部五个入口（手机）/ 左侧五项（桌面）：

- **记账**：本月概览、一句话输入、分类占比、最近账目；概览下方显示存钱目标进度。
- **明细**：按月、按类型、搜索，按日分组；点按编辑，左滑删除。
- **统计**：近 6 个月趋势、分类排行、日均与最大单笔。
- **存钱**：本月/全年存钱目标、已存金额、差额、进度条和可选口号。
- **设置**：固定月收入、导入账单、导出 CSV、数据说明、清空数据、关于。

## 3. 关键交互

### 3.1 一句话记账

- 首页固定输入条，提示语：`一句话，例如：午饭 25 微信`。
- 输入时实时解析，下方出现预览：`支出 · 餐饮 · ¥25.00 · 微信`。
- 按回车/点“记下”立即落库，出现“已记下 ¥25.00 · 餐饮”提示，可撤销。
- 没有识别到金额时不硬猜，转为打开“详细记一笔”，保留已输入的文字。
- 识别到金额但分类不确定时，归入“其他”，仍可直接保存，之后在明细里改。

### 3.2 详细记一笔

支出/收入分段切换；金额大号输入；分类网格；账户胶囊；日期选择；备注。编辑已有账目时同一张表单，底部提供删除。

### 3.3 导入账单

1. 选择 CSV / Excel（可多选）；
2. 自动识别微信/支付宝，展示：可导入、重复、跳过、收支合计；
3. 点“导入 N 笔”；
4. 完成后回到明细，并提示新增数量。

错误提示要具体：编码无法识别、找不到表头、不是支持的账单、空文件。

### 3.4 存钱

- 本月已存 = 本月收入 - 本月支出，与首页结余一致；今年已存按自然年累计。
- 目标分本月、全年，可随时修改或清除。
- 负数或未达目标用赤陶色，达到或超过目标用墨绿色。
- 顶部口号可选，例如「存够钱买手机」，留空显示提示文案。
- 设置里开启固定月收入后，每月 1 号自动生成一笔「工资」收入；关闭则手动记。

### 3.5 明细

- 顶部：月份切换、搜索、支出/收入筛选。
- 列表按日分组，日期右侧显示当日收支净额。
- 单条显示分类图标、商家/备注、账户、金额。
- 点按进入编辑；滑动删除需确认。

## 4. 分类体系

### 支出

餐饮、交通、购物、居住、娱乐、医疗、学习、人情、通讯、旅行、其他。

### 收入

工资、奖金、兼职、理财、退款、红包、报销、其他。

分类由关键词词典判定，长词优先、按命中权重累加；方向明确的词（工资/退款/报销）会反向决定收支方向。词典放在 `lib/domain/categories.dart`，后续可做成可编辑规则。

## 5. 一句话解析规则

处理顺序：

1. 规范化全角数字、空白、货币符号；
2. 先剥离日期表达，避免把 `11月3日` 的 11/3 当金额；
3. 识别收支方向：显式 `+/-`、收入词、支出词、分类词的默认方向；
4. 提取金额：优先带 `¥/元/块` 的数字，否则取最大数字；
5. 识别日期：今天/昨天/前天/大前天、`N月N日`、`M-D`、`N号`；
6. 识别账户：微信/支付宝/现金/银行卡及常见银行名；
7. 清洗备注，去掉日期、账户、金额、指令词；
8. 用清洗后的文本分类，返回预览。

默认：方向不明按支出；账户不明按“其他”；日期不明按当前时间。

## 6. 导入映射

| 统一字段 | 微信 | 支付宝 |
| --- | --- | --- |
| 时间 | 交易时间 | 交易创建时间 |
| 方向 | 收/支 | 收/支 |
| 金额 | 金额(元) | 金额（元） |
| 对方 | 交易对方 | 交易对方 |
| 商品 | 商品 | 商品名称 |
| 单号 | 交易单号 | 交易号 |
| 状态 | 当前状态 | 交易状态 |
| 账户 | 固定“微信” | 固定“支付宝” |

## 7. 数据模型

```sql
entries(
  id, occurred_at, direction, amount_cents, category, account,
  merchant, note, source, external_id, created_at, updated_at
)
unique(source, external_id) where external_id is not null
index(occurred_at)
```

金额一律用**分**存整数，避免浮点误差。时间存本地 ISO 字符串。

## 8. 视觉

- 纸张底色 `#F4F1EA`，卡片 `#FFFCF6`，墨色 `#20201D`；
- 支出用砖红 `#C05135`，收入用墨绿 `#3E7864`；
- 大数字、细分隔线、少量圆角，避免花哨渐变和阴影；
- 手机端内容左右 20px，桌面端最大宽度 760px，左侧导航 220px；
- 金额使用等宽数字特性，列表滚动时不跳动。

## 9. 验收

- 全新安装可完成：一句话记一笔、手动记一笔、导入一份微信 CSV、导入一份支付宝 Excel；
- 同一份 CSV / Excel 导入两次，第二次新增为 0；
- 删除、编辑后首页与统计同步更新；
- 无网络也能完成所有核心操作；
- Windows 可构建运行，Android 可打 APK。
