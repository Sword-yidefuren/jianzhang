# 进度（2026-11-27）：真机反馈修正

## 1. 撤掉纯黑白

真机看下来，黑白让统计分类、收入支出、存钱金额都变得难扫，确实改差了。

- 恢复暖白 + 墨黑 + 赤陶/墨绿的原语义色。
- 分类图标、分类环图、趋势图恢复各自颜色。
- 存钱大于 0 恢复墨绿，负数恢复赤陶。
- 黑白只保留在静态预览文件里，不进入正式主题。

## 2. 加号嵌入底栏

- 去掉 `FloatingActionButton` 和 `centerDocked` 的缺口。
- 底栏改成五个等宽位置：`记账 | 统计 | ＋ | 存钱 | 设置`。
- 加号是底栏内的 44px 圆形按钮，不再悬在内容上。

## 3. 搜索具体日期

搜索框支持：

- `11月3日`
- `2026-11-03`
- `11-03` / `11/3`
- `3号`
- `今天` / `昨天` / `前天`

日期会从关键词里拆出来，剩余文字继续匹配商家、备注、分类、账户。例如 `11月3日 午饭` 只看 11 月 3 日里的午饭。

## 4. 语音反馈
